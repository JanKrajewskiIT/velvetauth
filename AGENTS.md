# VelvetUi

SolidJS UI component library `@jankrajewskiit/ui` (VelvetUi). TypeScript, CSS Modules, Vite. Supports VelvetUi itself and consumer apps built on top.

Peers: `solid-js >=1.9`, `@solidjs/router >=0.15`.
