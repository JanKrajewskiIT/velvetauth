# Security policy

Do not disclose credentials or exploitable vulnerabilities in public issues. Use GitHub private vulnerability reporting when enabled, or the private reporting channel listed in the repository Security tab. If no private channel is configured, contact the maintainer privately before sharing details.

Supported releases are the latest published versions. Shared scanner policies, disclosure handling and deployment prerequisites are documented in [VelvetConfigs security controls](https://github.com/JanKrajewskiIT/velvetconfigs/blob/v3.5.0/security/README.md).
